**2. Azure Networking Concepts**

Revisited the fundamental networking components in Microsoft Azure and understood how they work together to provide network organization, isolation, and security.

* **Virtual Network (VNet):** Provides an isolated networking environment for Azure resources.
* **Subnet:** Divides a VNet into smaller network segments to organize and isolate resources.
* **Network Security Group (NSG):** Controls inbound and outbound traffic through security rules.
* **Resource Groups:** Logical containers used to organize and manage related Azure resources.
