#  Daily Learning: Azure Resource Groups, Virtual Machines & Bastion

Today, I continued my learning journey with **Microsoft Azure**, focusing on setting up cloud infrastructure, configuring networking and security, and securely accessing virtual machines.

###  What I Worked On Today

**1. Resource Group Creation**

* Created a Resource Group to organize and manage Azure resources.
* Understood how Resource Groups help manage related resources within a single logical container.

**2. Virtual Machine & Virtual Network Setup**

* Created and configured an Azure Virtual Machine.
* Set up a Virtual Network (VNet) to provide an isolated networking environment.
* Explored how virtual machines are connected to subnets within a VNet.

**3. Firewall & Network Security Configuration**

* Configured firewall and network security rules.
* Explored how inbound and outbound traffic can be controlled.
* Understood how network security configurations help restrict unauthorized access to cloud resources.

**4. Secure Access Using Azure Bastion**

* Configured and accessed the Virtual Machine using **Azure Bastion**.
* Understood how Bastion provides secure connectivity to VMs through the Azure portal without requiring a public IP address on the VM.
* Explored how it simplifies secure remote access to cloud infrastructure.
